# AI Boundary Rules

- Only modify files related to the current task.
- Do not refactor unrelated code.
- Do not rename public APIs unless explicitly requested.
- Before coding, identify impacted classes.
- Before editing, summarize planned changes.
- After editing, summarize changed files and risks.
- If business rule is unclear, mark it as TODO/question instead of inventing behavior.
- Prefer small incremental changes.
